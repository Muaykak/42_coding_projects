# What is OSI ?

The **OSI (Open Systems Interconnection) Model** is a set of rules by **International Organization for Standardization (known widely as ISO).** It explains how different computer systems communicate over a network. This OSI Model has 7 layers. This way makes it easier for different devices and technologies to work together.

# OSI Layers

\> [Physical Layer](#physical-layer)

## Physical Layer

This is the lowest layer. It is the actual **physical connection between devices**. This layer contains information in the form of bits. (It' the signal information like 010101)

- **Physical Layer** is responsible for transmitting bits information from one node to the next
- This layer will **convert the recieving data into 0s and 1s and send them to **Data Link layer**

So basically, the connection between each device will **always** comes down to the **Physical Layer**. Then The reciever will go from it's Physical Layer up to the application we are using.

- Common physical layer devices are Hub, Repeater, Modem, and Cables.

So its the Physical transmission.

### **Functions of the Physical Layer**
- **Bit Synchronization:** Between connections, to avoid Data Loss. Both sender and receiver need to be in sync. A clock. This clock controls both sender and receiver to providing synchronization at the bit level.
-  **Bit Rate Control:** The Physical Layer also defines the transmission rate. Usually what we see is like the internet speed. the number of bits sent per second.
-  **Physical Topologies:** Physical later specifies how the different, devices/nodes are arranged in a network. You may want to know The [**Network Topology**](./Network_Topology.md) but its not relate much to subject but Also good to know.
